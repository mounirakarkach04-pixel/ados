Politique de confidentialité

État documentaire : 24 octobre 2026.

Responsable : Mounir Akarkach, contact écrit : moakarkach@hotmail.de. Pour les mentions légales : PIGA Pocket.

Données traitées par le prototype

Le prototype LA PREUVE LAB est destiné exclusivement aux exemples fictifs. Les valeurs saisies sont traitées en mémoire dans le navigateur pour afficher une comparaison arithmétique et un journal de session. L'application ne transmet pas les champs de contrôle à un serveur, ne crée aucun compte utilisateur et ne déploie aucun service d'analyse tiers. Le journal disparaît lorsque l'onglet est rechargé ou fermé. Un export téléchargé reste sous le contrôle de la personne qui l'a généré.

Données techniques

La distribution statique peut impliquer les journaux techniques habituels d'hébergement (adresse IP, date, ressource demandée, agent utilisateur), selon les conditions du fournisseur d'hébergement de PIGA Pocket. Un service worker peut stocker localement le code de l'application pour l'accès hors ligne ; cela ne constitue pas un transfert des données du formulaire.

Précaution

Ne saisissez jamais de nom, identifiant, date de naissance, résultat biologique réel ou autre donnée de patient. Ce prototype n'a pas été conçu pour traiter des données de santé.

Droits et contact

Pour toute demande sur les données techniques du site, veuillez écrire à moakarkach@hotmail.de. L'application fonctionne en local, de sorte que l'auteur ne peut pas supprimer une exportation enregistrée sur votre appareil ; vous pouvez l'effacer vous-même.
